# Nền tảng API Ví điện tử đa đối tác 
Hệ thống Backend cung cấp các API quản lý ví và xử lý giao dịch tài chính mô phỏng, cho phép nhiều đối tác tích hợp vào ứng dụng của họ. Như app đặt xe, websites của các shop, các đối tác muốn có hệ thống hỗ trợ giao dịch mà không phải tốn tài nguyên xây dựng từ đầu.
